# IconButton

Square icon-only button with a required accessible `label`.

- `ghost` for toolbars and headers, `raised` for Stop while a draft is typed, `primary` for the round Send button.
- 32px by default, 28px with `size="sm"` inside cards and headers.
- The label doubles as the tooltip. Write it as an action: "Add files or images", "Close Delegated work".
