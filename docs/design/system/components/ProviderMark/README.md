# ProviderMark

Placeholder mark that identifies the owning provider of a chat, reply or task.

- Provide `provider` (`codex` or `claude`), `size` (14 in rows, 16 in tasks, 20 on setup cards) and `tone`.
- `tone="muted"` in unselected sidebar rows, `color` when selected and in Delegated work and menus.
- These shapes are placeholders. Replace them with each provider's official mark before release, keeping sizes and the accessible names.
- Never put a provider mark inside the composer.
