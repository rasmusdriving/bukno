# StateChip

The open chat's run state beside its title: glyph, one word, and elapsed time when it helps.

- Provide `state`, `provider` and optional `time` ("2m 14s").
- Use the words people expect: Working, Needs approval, Done, Stopped, Failed, Outcome unknown, Reconnecting.
- The chip is the one live indicator for the run. Do not add another spinner beside the reply.
