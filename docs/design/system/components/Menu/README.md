# Menu

Popover menu for profile, chat and permission menus.

- Provide `items`: `item` (label, detail, icon or provider, end text, kbd, tag, check), `section`, `divider`, `usage` (a `UsageMeter`), or `note` (a quiet explanatory line, such as how an engine enforces a permission).
- Use `tag: "Later"` for entries that belong to a later milestone, so the design never silently expands scope.
