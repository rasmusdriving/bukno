# ModelControl

Closed model control: one lightning, the model name, a quieter effort label and one chevron.

- Provide `provider`, `model`, `effort`, `level` and `fast`.
- The lightning takes the provider's effort ramp colour: dim at low effort, bright at high. Filled means fast mode is on, outlined means off.
- Keep the four parts about 6px apart. No provider logo.
- `pending` marks a change that applies from the next turn.
