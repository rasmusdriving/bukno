# Fonts

Geist and Geist Mono by Vercel, from the official release
[v1.7.2](https://github.com/vercel/geist-font/releases/tag/v1.7.2)
(`geist-font-v1.7.2.zip`, SHA-256
`7fc800d2ac6b92844895196e5041aca55d814c15db70c44f79b3b83ab82b04e2`).
Licensed under the SIL Open Font License 1.1, see [OFL.txt](OFL.txt).

Only the weights the design system uses are bundled: Geist 400, 500 and 600,
and Geist Mono 400. They are compiled into the app binary, so nothing is
downloaded at runtime. `SHA256SUMS` records the exact files.
